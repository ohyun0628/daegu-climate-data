# Daegu Climate & Carbon Neutrality Data Analysis

2026 대구광역시 기후·환경·탄소중립 공공데이터 AI 활용대회 (부문 2: 공공데이터 분석·시각화) 프로젝트 저장소입니다.

## 1. 분석 주제
- **배경:** 대구광역시 온실가스 배출량 중 건물 부문 비중(약 58.4%)이 가장 높으며, 여름철 폭염 일수 및 강도가 냉방 전력 수요에 직접적인 영향을 미침.
- **목표:** 대구 구·군별 기상 데이터(폭염·냉방도일)와 건물 에너지 사용량 및 노후 건축물 현황을 결합하여, 기후변화 민감도가 높은 지역을 도출하고 탄소중립 우선 투자 타깃을 시각화함.

## 2. 디렉터리 구조
```text
daegu-climate-data/
├── data/
│   ├── raw/          # 원본 공공데이터
│   └── processed/    # 구·군 및 연·월 단위로 정제·병합된 데이터
├── src/
│   ├── collect/      # 데이터 수집 스크립트
│   ├── preprocess/   # 결측치 처리, 행정구역·시계열 기준키 통일, 파생변수 생성
│   └── model/        # 데이터 분석 및 모델링
└── docs/             # 데이터 출처 정리 및 분석 보고서 자료
```

## 3. 진행 단계
1. **데이터 수집 (`data/raw/`, `docs/data_sources.md`)**
   - 대구시 온실가스 인벤토리, 기상청 기온 관측 자료, 구·군별 건물 에너지 및 건축물 현황 수집
2. **데이터 전처리 (`src/preprocess/`)**
   - 구·군 단위 및 시계열(연·월) 기준키 통일, 냉방도일(CDD) 등 파생지표 산출
3. **분석 및 시각화 (`src/model/`)**
   - 구·군별 폭염-에너지 민감도 분석, 군집화 및 시각화 대시보드 제작
